# 内容质量规则

## 入选原则

默认展示 6 条信号。窗口内全部新闻都由 LLM 分批给出 0-100 分、类别和短排名理由，阅读、点赞和分享仅作为市场关注度证据，不直接决定顺序。

- 优先：合作、授权、BD、并购、融资、审评、获批、申报、政策、GMP、商业化与出海。
- 相关领域：创新药、临床、抗体、ADC、疫苗、细胞/基因治疗、核酸、AI 制药、CRO/CDMO、诊断与器械。
- 排除：泛健康科普、高互动养生文章、会议议程、活动预告、报名和招聘信息。
- 去重：所有转载都进入 LLM 排名和 `ranking.json`；进入综合分析前，相同标题只保留分数最高的一条。

排名标尺和整期写作要求位于 `prompts.py`。模型必须逐条返回输入 ID，任何遗漏、额外 ID、非法分数或分类都会使生成失败。

## 标签原则

“本期重点公司 / 机构”和“本期重点药物 / 技术类型”由第二阶段 LLM 根据最终候选的事实证据生成，各最多 5 个。

最终标题、来源、日期和链接不采用模型生成值，而是通过 `article_id` 回填原始文章；模型只能生成排名、摘要、分类、分析和标签，降低事实漂移风险。

## 人工编辑门槛

发布前人工确认以下事项：

- 每条标题、摘要、来源日期和链接与原始文章一致。
- “监管 / 政策 / 竞争 / 机会”分类符合标题所述事件。
- `So What` 是业务提醒而非未经来源支持的事实结论。
- 不含医疗建议、投资建议、夸大疗效或无来源的数字结论。
- 标签和主题与本周窗口确实相关。

当输入数据不足以支持 6 条高质量信号时，宁可少于 6 条，不用低相关内容凑数。

审核工作台使用 `articles.json` 原文快照检查摘要与业务影响中的数字和强调性表述。自动质检是审阅提示，不替代人工判断；未保存原文、缺少链接或证据无法直接匹配时必须在发布前复核。
